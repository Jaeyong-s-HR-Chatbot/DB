# 퇴직연금 규정 정리

기준: rag에 적재된 누리철도㈜ 규정 33건 중 「퇴직급여 지급 규정」과 「퇴직급여 지급 규정 시행세칙」, 그리고 법령 13건 중 근로자퇴직급여 보장법과 시행령. 조문은 원문 요약이며, 답변에 쓸 때는 원문을 인용한다.

## 1. 한눈에

| 질문 | 근거 | 답 |
|---|---|---|
| 퇴직급여란 | 규정 제3조 | 퇴직금과 퇴직연금을 합친 말 |
| 퇴직연금 종류 | 규정 제3조 제7호 | 확정급여형(DB), 확정기여형(DC). 퇴직금은 IRP로 이전해 지급 |
| 퇴직금 계산 | 규정 제4조 | 직원은 근속 1년당 퇴직 당시 평균임금 30일분. 근속 1년 이상 |
| DB 가입자 한도 | 규정 제5조 | 퇴직급여는 제4조 퇴직금을 초과할 수 없음 |
| DC 회사 부담금 | 규정 제5조 | 연간임금총액의 1/12을 초과할 수 없음 |
| 중간정산 | 규정 제6조 | 퇴직연금 가입 직원은 제외. 법정 사유일 때만 가능 |
| 가입·변경 | 시행세칙 제4조 제1항 | 가입(변경) 신청서(별지 제7호)를 퇴직급여지급소속장에게 제출 |
| 지급 방법 | 시행세칙 제4조 제2항, 제7조 제2항 | 직원이 지정한 IRP 계좌로 이전 |
| IRP 이전 예외 | 같은 조항 | 55세 이후 퇴직, 담보대출 상환, 고용노동부장관이 정한 금액 이하 |
| 지급 시기 | 시행세칙 제7조 제1항 | 지급사유 발생일부터 14일 이내 (합의로 연장 가능) |
| 단수 처리 | 시행세칙 제8조 | 최종합계액에서 10원 미만 절상 |

## 2. 퇴직급여 지급 규정

| 조 | 제목 | 핵심 |
|---|---|---|
| 제1조 | 목적 | 임·직원의 퇴직급여 지급 기준과 절차 |
| 제2조 | 적용범위 | 임·직원 |
| 제3조 | 정의 | 평균임금, 월평균보수, 퇴직급여, 퇴직금, 명예퇴직금, 희망퇴직금, 퇴직연금 |
| 제4조 | 퇴직금 지급대상·기준 | 근속 1년 이상. 임원은 1년당 월평균보수 1개월분, 직원은 1년당 평균임금 30일분 |
| 제4조의2 | 임원 퇴직금 제한 | 금고 이상 형 확정, 해임 등이면 2분의 1 감액. 수사·재판 중이면 지급 정지 가능 |
| 제5조 | 퇴직연금 가입 | DB·DC 규약에 따름. DB는 제4조 금액 초과 불가, DC 부담금은 연 임금총액 1/12 초과 불가 |
| 제6조 | 퇴직금 중간정산 | 1년 이상 근속, 퇴직연금 가입자 제외, 법정 사유. 정산 후 근속기간은 새로 기산 |
| 제7조 | 근속기간 계산 | 임용일부터 지급사유 발생일까지. 소재불명, 외부 고용, 일부 휴직 기간은 제외. 12개월=1년, 1개월 미만 잔여일은 1개월 |
| 제8조 | 명예퇴직금 | 정년 잔여기간별로 기본급 1/2 또는 1/4 기준 산정 (제8조 제2항 참조) |
| 제9조 | 희망퇴직금 | 퇴직 당시 기본급의 6개월분 |
| 제10조 | 수령권자 | 본인, 사망 시 유족(민법 상속 순위) |
| 제11조 | 최저지급액 | 법상 최저 기준에 미달하면 법상 최저액 지급 |

## 3. 시행세칙

| 조 | 제목 | 핵심 |
|---|---|---|
| 제2조 | 정의 | 퇴직급여지급소속장(별표1), 소속장 |
| 제3조 | 신청서류 | 퇴직급여청구서(별지 1), 중간정산 청구서(별지 2)와 별표2 증빙, 명예·희망퇴직금 청구서, 통장 사본 |
| 제4조 | 퇴직연금 가입·변경신청 및 지급방법 | 위 표 참조 |
| 제5조 | 지급의뢰·서류보관 | 중간정산 증빙은 퇴직 후 5년이 되는 날까지 보존 |
| 제6조 | 퇴직급여 공제 | IRP 이전분을 제외하고 중간정산액, 공제조합 대출금, 대여학자금, 제세공과금 등 공제 후 지급 |
| 제7조 | 지급 | 14일 이내, 직원은 IRP 이전 원칙 |
| 제9조 | 수령권자 경합 | 동순위 유족이 여럿이면 균등 분배, 대표자 위임 가능 |
| 별표 1 | 지급소속장·담당소속 | 본사, 본부별 지급소속장 목록 |
| 별표 2 | 중간정산 사유별 증빙서류 | 주택 구입, 전세금, 6개월 이상 요양, 파산·개인회생, 임금피크, 천재지변별 서류 |
| 별지 1~10 | 서식 | 청구서, 신청서, 확인서 등 |

## 4. 연결되는 법령 (rag 법령 13건 중)

| 조문 | 내용 |
|---|---|
| 근로자퇴직급여 보장법 시행령 제2조 | 주택 구입, 전세금, 6개월 이상 요양 의료비, 파산, 개인회생, 학자금·혼례·장례비, 휴업·재난 등의 사유 |
| 같은 시행령 제14조 | DC형 중도인출 사유 |
| 같은 시행령 제18조 | 개인형퇴직연금(IRP) 급여 종류별 수급요건 (55세 이상 연금·일시금), 중도인출 사유 |
| 같은 시행령 제32조 | 가입자 교육 내용 (제도별 특징, 담보대출·중도인출, 세제 등) |

## 5. 우리 자료에 없는 것

| 없는 것 | 영향 |
|---|---|
| 확정급여형 퇴직연금규약, 확정기여형 퇴직연금규약 | 규정 제5조가 "별도로 정한다"고 했지만 문서가 없음. 운용 방법, 상품 선정, 수수료 부담, 가입·변경 시기 제한 등 세부 확인 불가 |
| 직원별 가입 제도(DB/DC) 데이터 | 가상 데이터로 대체 (pension_plans.csv) |
| 운용상품 목록 | 가상 데이터로 대체 (pension_products.csv) |
| 퇴직소득세, 연금소득세 | 소득세법 확인 필요 (법령 13건에 포함 여부 미확인) |

## 6. 주의

- 앞선 설명에서 DC 회사 납입을 "연 임금의 1/12 이상"이라고 했으나, **누리철도 규정 제5조는 부담금이 1/12을 초과할 수 없다**고 되어 있다. 이 문서 기준이 맞다. (법은 최저 기준을 정하고 규정은 상한을 정한 것으로 보이며, 규약 확인 필요)
- 챗봇에서는 이 표를 그대로 답으로 쓰지 말고 조문을 인용한다.
